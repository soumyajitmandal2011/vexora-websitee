# VEXORA design finishing pass

This package is a local, unpublished design update based on the existing VEXORA V8 files.

## What changed
- Added `final-design-polish.css` to the main pages for consistent spacing, navigation polish, card depth, button hover feedback, readable text measure, form styling, and visible keyboard focus.
- Added `business-final-polish.css` to the ten industry demo pages for consistent controls, responsive spacing, and reduced-motion support.
- Kept the existing HTML structure, 3D scripts, service content, template pages, auth preview files, and business demos in place.
- Added reduced-motion handling and keyboard focus styles as a usability improvement.

## Local preview
1. Extract this ZIP.
2. Open the extracted `vexora-website` folder.
3. Open a terminal in that folder and run `npx serve .` (Node.js is required).
4. Open the localhost address printed by the terminal.

This package is not published. The contact form and account/authentication features may still require their respective service configuration; the design update does not claim to configure a backend.
